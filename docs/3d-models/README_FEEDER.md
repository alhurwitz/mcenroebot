# Feeder (V4) 3D parts

Parametric parts for the spin/aim ball machine (see `../V4_PLAN.md`). Generated by
`generate_feeder_parts.py` — the same trimesh idiom as `generate_parts.py`. All parts are
watertight manifolds. Units mm.

## Regenerate

```bash
python3 generate_feeder_parts.py
```

Writes `F1_escapement_disk.stl` … `F5_launch_wheel.stl` into this folder. No new deps beyond
what `generate_parts.py` already uses (numpy + trimesh + a boolean backend). Edit the constants
block at the top to retune any dimension.

## Assembly notes / things the blanks don't encode

- **Escapement housing (not generated).** `F1` is the indexing disk only. It needs a housing/
  baseplate that places the hopper **load port** and the **discharge port** both at radius
  `POCKET_CENTER_R` (22 mm), at different angles, with the disk's solid face sealing both between
  index steps. `F2`'s 50 mm outlet funnels into the load port — it is **not** meant to dump on the
  disk axis. Design the housing once the disk + servo coupling is in hand.
- **Disk drive.** Four M3 holes on a 16 mm BC (underside) bolt to a continuous-rotation servo horn;
  the 608 counterbore + 8 mm pivot bore take the radial load off the servo shaft.
- **Auger stacking.** `F3` is 2 full turns, so flights align when segments are threaded onto the
  8 mm rod — keep them rotationally indexed and the flight is continuous. Grub screw per segment.
- **Auger inlet.** The **bottom** tube section needs a side window cut for ball entry from the
  trough — not in the generic `F4`. Add a `~50 × 40 mm` slot near its base (or set a flag in the
  generator) for the inlet section.
- **Launch wheel bore.** `WHEEL_BORE` defaults to 5 mm — **measure your A2212 collet adapter and
  retune** before printing. Grub screw locks to the shaft/collet flat.

## Validation (as generated)

All five export watertight (`is_watertight = True`, `is_volume = True`). Face counts 1.3k–2.4k;
files are small. Re-running the generator reproduces them exactly.
